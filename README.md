## 🐍 Snake Contribution

<div align="center">
<img src="https://raw.githubusercontent.com/GuxtaDev007/GuxtaDev007/output/github-contribution-grid-snake-dark.svg" width="100%"/>

<details>
<summary>⚙️ Como ativar a animação da cobrinha (clique para expandir)</summary>

<br/>

1. Crie o arquivo `.github/workflows/snake.yml` no seu repositório `GuxtaDev007/GuxtaDev007` com o conteúdo abaixo.
2. Vá em **Settings > Actions > General** e habilite permissão de leitura/escrita para o workflow.
3. Rode o workflow manualmente uma vez (ou aguarde o agendamento).

```yaml
name: Generate Snake Animation
on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches: [ main ]

jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
            dist/github-contribution-grid-snake.svg
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
